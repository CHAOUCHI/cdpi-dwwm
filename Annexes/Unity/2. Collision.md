# COllision


## Fonction event Collide

Dans un GameObject qui possède un `BoxCollider2D`, ajoutez la fonction `OnCollisionEnter2D` pour réagir à l'event collision.

*Affichez le nom et le tag du gameobject qui rentre en collision*
```cs
void OnCollisionEnter2D(Collision2D other)
{
    // Debug.Log("Aïe Aïe Ouille !");
    Debug.Log(other.gameObject.name);
    Debug.Log(other.gameObject.tag);
}
```

1. Ajouter un BoxCollider2D au Player
2. AJouter un script au Player
3. Ajouter la fonction OnCollisionEnter2D dans ce script


*exemple complet*
```cs
using UnityEngine;

public class playerlife : MonoBehaviour
{
    Rigidbody2D rb;
    Transform tr;
    public float jumpSpeed = 350f;
    public float speed = 50f;
    // Start is called once before the first execution of Update after the MonoBehaviour is created
    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
        tr = GetComponent<Transform>();
    }

    // Update is called once per frame
    void Update()
    {
        rb.AddForce(new Vector2(speed * Input.GetAxis("Horizontal"), 0));
        if (Input.GetKeyDown(KeyCode.Space))
        {
            rb.AddForce(new Vector2(0, jumpSpeed),ForceMode2D.Impulse);
        }
    }

    void OnCollisionEnter2D(Collision2D other)
    {
        // Debug.Log("Aïe Aïe Ouille !");
        Debug.Log(other.gameObject.name);
        
        if (other.gameObject.tag == "Respawn")
        {
            tr.position = new Vector2(-6, 0);
        }

    }
}
```
