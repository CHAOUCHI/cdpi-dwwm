## Lire un dossier

Pour lire dans un dossier, il faut utiliser la fonction `fs.readdir()`.

```js
import fs from "fs";

fs.readdir("mon_dossier", (error_obj, files_arr) => {
    console.log(error_obj);

    console.log(files_arr); // J'affiche le nom des fichiers
});
```
Le tableau files_arr contient le nom des fichiers du dossier.

Vous pouvez donc utiliser fs.readFile pour lire chacun des fichiers.

```js
import fs from "fs";

fs.readdir("mon_dossier", (error_obj, files_arr) => {
    console.log(error_obj);

    files_arr.forEach(file_str => {
        fs.readFile(`mon_dossier/${file_str}`, (error_obj, dataBuffer_obj) => {
            if(error_obj) {
                console.log("Erreur de lecture du fichier :", error_obj);
                return;
            }
            console.log("Fichier lu !");
            console.log(dataBuffer_obj.toString());
        });
    });
});
```
