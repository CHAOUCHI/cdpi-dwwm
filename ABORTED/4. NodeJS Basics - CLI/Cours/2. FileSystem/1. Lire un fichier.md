## Lire un fichier

Pour lire un fichier, il nous faut un fichier à lire. Créez-en donc un qui contient le texte : Bonjour tout le monde.

```bash
touch mon_fichier && echo "Bonjour tout le monde" > mon_fichier
```

Votre projet devrait maintenant ressembler à ceci :

```
projet_fs/
----app.js
----mon_fichier
```

### fs.readFile()

La fonction readFile permet de lire un fichier. La lecture d'un fichier est considérée comme une opération qui prend du temps ; readFile est donc une fonction asynchrone. C'est-à-dire une fonction dont le résultat est disponible en paramètres d'une fonction callback.

```js
import fs from "fs";

fs.readFile("mon_fichier", (error_obj, dataBuffer_buf) => {
    console.log("Fichier lu !");
});
```

- Le premier paramètre de readFile est le chemin vers le fichier, ici la chaîne `"mon_fichier"`.
- Le second paramètre de readFile est une fonction à laquelle readFile fournira, en tant que paramètres : `error_obj` et `dataBuffer_buf`, des variables qui contiennent les éventuelles erreurs de lecture et les données du fichier.

```js
import fs from "fs";

fs.readFile("mon_fichier", (error_obj, dataBuffer_buf) => {
    console.log("Fichier lu !", error_obj);

    // error_obj doit être null, sinon affiche les messages d'erreur.
    console.assert(error_obj === null, error_obj?.message, error_obj?.cause, error_obj);

    console.log(dataBuffer_buf); // Buffer des données
});
```

Le résultat doit être celui-ci, une suite d'octets qui représentent chacun un caractère de notre fichier.

```bash
Fichier lu ! null
<Buffer 42 6f 6e 6a 6f 75 72 20 74 6f 75 74 20 6c 65 20 6d 6f 6e 64 65 0a>
```

Je peux connaître la taille de mon fichier et donc le nombre de caractères avec l'attribut length du buffer.

```js
import fs from "fs";

fs.readFile("mon_fichier", (error_obj, dataBuffer_buf) => {
    console.log("Fichier lu !", error_obj);
    // error_obj doit être null, sinon affiche les messages d'erreur.
    console.assert(error_obj === null, error_obj?.message, error_obj?.cause, error_obj);
    console.log(`Mon fichier fait ${dataBuffer_buf.length} caractères donc ${dataBuffer_buf.length} octets !`);
    console.log(dataBuffer_buf); // Buffer des données
});
```

Je peux même afficher chaque octet et donc chaque lettre de mon fichier.

```js
import fs from "fs";

fs.readFile("mon_fichier", (error_obj, dataBuffer_buf) => {
    console.log("Fichier lu !", error_obj);
    // error_obj doit être null, sinon affiche les messages d'erreur.
    console.assert(error_obj === null, error_obj?.message, error_obj?.cause, error_obj);
    console.log(dataBuffer_buf); // Buffer des données
    dataBuffer_buf.forEach(octet_number => {
        console.log(octet_number);
    });
    console.log(`Mon fichier fait ${dataBuffer_buf.length} caractères donc ${dataBuffer_buf.length} octets !`);
});
```

### Lire un fichier texte

Pour lire les données du fichier comme une chaîne de caractères, il faut utiliser la fonction dataBuffer_buf.toString().

```js
import fs from "fs";

fs.readFile("mon_fichier", (error_obj, dataBuffer_buf) => {
    console.assert(error_obj === null, error_obj?.message, error_obj?.cause, error_obj);

    console.log(dataBuffer_buf.toString());
});
```

```
Bonjour tout le monde
```

Je peux aussi changer l'encodage en ajoutant des options en second paramètre de readFile.

```js
import fs from "fs";

fs.readFile("mon_fichier", { encoding: "ascii" }, (error_obj, data_str) => {
    console.assert(error_obj === null, error_obj);

    console.log(data_str); // Bonjour tout le monde
});
```

### Lire un fichier JSON

1. Créez ce fichier nommé *fruits.json* :

```json
[
    {
        "nom": "pomme",
        "couleur": "rouge",
        "saison": "automne"
    },
    {
        "nom": "cassis",
        "couleur": "noir",
        "saison": "été"
    },
    {
        "nom": "framboise",
        "couleur": "rouge",
        "saison": "été"
    }
]
```

Pour lire un fichier JSON, il faut lire un fichier contenant du JSON. Le contenu d'un fichier JSON n'est qu'un texte.

Il faut donc décoder le fichier en UTF-8, le format qui permet les emojis et tous les types de caractères acceptés sur le web.

Les données reçues sont une chaîne de caractères, comme pour la lecture d'un fichier texte.

J'utilise la fonction `JSON.parse` pour transformer les données texte JSON en une véritable variable JavaScript nommée `fruits_arr`.

Pour chacun des fruits, j'affiche ensuite son nom et sa couleur.

```js
import fs from "fs";

fs.readFile("fruits.json", { encoding: "utf8" }, (error_obj, data_str) => {
    console.assert(error_obj === null, error_obj);

    const fruits_arr = JSON.parse(data_str);

    fruits_arr.forEach(fruit_obj => {
        console.log("Je suis une", fruit_obj.nom, "de couleur", fruit_obj.couleur);
    });
});
```

```
Je suis une pomme de couleur rouge
Je suis une cassis de couleur noir
Je suis une framboise de couleur rouge
```
