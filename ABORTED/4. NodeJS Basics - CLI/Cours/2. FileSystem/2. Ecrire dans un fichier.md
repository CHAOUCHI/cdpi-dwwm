
## Écrire dans un fichier

### Écrire du texte

```js
import fs from "fs";

const texte_str = `Salut tout le monde !!`;

fs.writeFile("mon_fichier", texte_str, (error_obj) => {
    console.assert(error_obj === null, error_obj);
});
```

### Écrire du JSON

```js
import fs from "fs";
const fruits_arr = ["pomme", "cassis", "framboise"];

fs.writeFile("fruits.json", JSON.stringify(fruits_arr), (error_obj) => {
    console.assert(error_obj === null, error_obj);
});
```

### Écrire un fichier binaire - Enregistrer un fichier

Pour montrer comment enregistrer un fichier, nous allons coder une petite commande de copier-coller.

Pour enregistrer un fichier, il suffit d'écrire chacun de ses octets dans un autre fichier. Nous avons donc tous les outils pour réaliser cette tâche.

Pour écrire dans un fichier, il faut utiliser la fonction fs.writeFile. Pour lire le fichier à écrire, il suffit d'utiliser la fonction fs.readFile.

#### Comment récupérer les arguments de la ligne de commande ?
Pour récupérer les arguments de la ligne de commande, il faut utiliser `process.argv`.
`process.argv` est un tableau qui contient les arguments passés en ligne de commande.

1. Créez un fichier `copy-paste.js`.

2. Lancez le script avec un argument de chemin de fichier.
```bash
node copy-paste.js mon_fichier
```
Ici j'ai deux arguments : ``copy-paste.js`` et ``mon_fichier``.

2. Affichez les arguments de la ligne de commande via le tableau `process.argv` et un console.log.

```js
import process from "process";
console.log(process.argv);
```


#### Exemple de copier-coller de fichier

1. Créez un fichier `mon_fichier` avec du texte dedans.

2. Créez le fichier `copy-paste.js` avec le code suivant.

*copy-paste.js*
```js
import fs from "fs";
import path from "path";
import process from "process";

const FILE_PATH_ARGV_INDEX_number = 2;

console.log("argv_arr", process.argv);

if (process.argv.length < FILE_PATH_ARGV_INDEX_number + 1) {
    console.error("ERROR : File_path missing");
    console.info("node copy-paste.js /chemin/vers/mon/fichier");
    process.exit(-1);
}

const file_path_str = process.argv[FILE_PATH_ARGV_INDEX_number];

fs.readFile(file_path_str, (error_obj, dataBuffer_obj) => {
    console.assert(error_obj === null, error_obj);

    const new_file_name_str = `${file_path_str + Date.now().toString()}`;

    fs.writeFile(new_file_name_str, dataBuffer_obj.toString(), (error_obj) => {
        console.assert(error_obj === null, error_obj);

        console.log(`New file created : Successfully ${new_file_name_str} !`);
    });
});
```

```bash
node copy-paste.js mon_fichier
```

> Vérifiez bien que le fichier existe avant de lancer le programme, sinon il plantera.
