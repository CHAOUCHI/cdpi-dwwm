# Symfony UX Turbo
Turbo est une librairie JavaScript développée par l'équipe de Basecamp (les créateurs de Ruby on Rails) qui permet de créer des applications web réactives en utilisant du rendu côté serveur et de mise à jour partielle du DOM.

Documentation : https://symfony.com/bundles/ux-turbo/current/index.html

## Installation
Installer le bundle Symfony UX Turbo :
```bash
composer require symfony/ux-turbo
```

## Qu'est ce que c'est ?
Turbo permet de faire du rendu côté serveur et de mettre à jour le DOM de manière partielle, ce qui permet de créer des applications web réactives sans avoir à écrire du JavaScript côté client. 

Turbo utilise des requêtes AJAX(fetch) pour récupérer du HTML depuis le serveur et mettre à jour le DOM en conséquence.

Concrètement grâce à ux turbo quand on clique sur un lien `<a>` ou un formulaire `<form>` : 
1. la requete est intercepté par le JavaScript de Turbo et empeche donc le rechergement de page.
2. Turbo envoie une requete AJAX(fetch) au serveur pour récupérer le HTML de la page ciblé par le lien ou le formulaire.
3. Mais Turbo ne remplace pas tout le DOM de la page par le HTML récupéré, il va juste remplacer une partie du DOM ciblé par un attribut comme l'`id`.

> Il n'y a donc pas besoin d'API REST ou de JSON pour avoir une application web SPA avec Symfony, on na a vrai dire même pas besoin d'ecrire de JavaScript car tout à été encapsulé dans des attributs et des balises HTML utilisable dans twig.

## Comment êmpecher le rechargement de la page lors du clic sur un lien ou la soumission d'un formulaire ?

Il suffit d'encapluser une balise dans un balise <turbo-frame> et lui donner un id unique.

1. Indentifier le DOM qui doit être dynamique, ici par exemple j'ai une tâche avec un formulaire de validation de la tâche :
```html
<div class="flex border border-black/10 rounded-xl content-center justify-between p-4 w-2/3" {{attributes}}>
    <div class="flex gap-3 items-center justify-start">
        <!-- Ce formulaire va recharger toute la page, alors que je veux juste mettre à jour l'affichage "En cours"/"Terminé" et l'etat de la checkbox -->
        <form action="{{path('app_task_done',{id : id})}}" method="post">
            <input type="hidden" name="token" value="{{ csrf_token('validate-'~id) }}">
            <input type="checkbox" onclick="this.form.submit()" {{ this.isDone ? "checked" : "" }} name="is_done" id="is_done" class=" w-4 h-4 bg-[#F3F3F5] border border-black/10 rounded-sm">
            <button class="btn"></button>
        </form>

        <div class="flex flex-col">
            <div class="flex gap-2 text-[#101828] items-center">
                <p>{{ title }}</p>
                <p class="rounded-lg px-2 border text-xs h-min {{ this.priorityToCss }}">
                    {{priority}}
                </p>
            </div>
            <!-- Affichage de l'état de la tâche -->
            <p class="text-[#6A7282] text-xs">{{ not this.isDone ? "En cours" : "Terminé"}}</p>
        </div>
    </div>
    <i class="fa-solid fa-thumbtack flex content-center text-[#99A1AF]"></i>
</div>
```

2. Encapsuler ce DOM dans une balise `<turbo-frame>` et lui donner un id unique :
```html
<turbo-frame id="task-{{ id }}" class="flex border border-black/10 rounded-xl content-center justify-between p-4 w-2/3" {{attributes}}>
    <div class="flex gap-3 items-center justify-start">
        <!-- Ce formulaire va recharger toute la page, alors que je veux juste mettre à jour l'affichage "En cours"/"Terminé" et l'etat de la checkbox -->
        <form action="{{path('app_task_done',{id : id})}}" method="post">
            <input type="hidden" name="token" value="{{ csrf_token('validate-'~id) }}">
            <input type="checkbox" onclick="this.form.submit()" {{ this.isDone ? "checked" : "" }} name="is_done" id="is_done" class=" w-4 h-4 bg-[#F3F3F5] border border-black/10 rounded-sm">
            <button class="btn"></button>
        </form>

        <div class="flex flex-col">
            <div class="flex gap-2 text-[#101828] items-center">
                <p>{{ title }}</p>
                <p class="rounded-lg px-2 border text-xs h-min {{ this.priorityToCss }}">
                    {{priority}}
                </p>
            </div>
            <!-- Affichage de l'état de la tâche -->
            <p class="text-[#6A7282] text-xs">{{ not this.isDone ? "En cours" : "Terminé"}}</p>
        </div>
    </div>
    <i class="fa-solid fa-thumbtack flex content-center text-[#99A1AF]"></i>
</div>
```

3. C'est FINI ! 

### Pourquoi ça marche ?
Maintenant quand on soumet le formulaire:
1. la requete est intercepté par Turbo qui envoie une requete AJAX(fetch) au serveur pour récupérer le HTML de la page ciblé entière
2. Mais Turbo remplace juste la partie du DOM ciblé par l'id "task-{{ id }}" par le nouveau HTML récupéré.


## Comment faire si le formulaire est en dehors du trubo-frame ?

Parfois le formulaire est en dehors du turbo-frame.

```html
<!-- Mon formulaire est en dehors du turbo-frame ! -->
<form action="{{path('app_dashboard')}}">
    <!--  -->
</form>
<!-- Le contenu que je veux uniquement recharger -->
<turbo-frame id="taskfiltered" >
    <div class="container">
        {% for task in tasks %}
        <div>
            <p>tache {{ task.id }}</p>
        </div>
        <div>
            <p>tache {{ task.id }}</p>
        </div>
        {% endfor %}
    </div>
</turbo-frame>
```

Dans ce cas il faut :

1. Ajouter `data-turbo-frame` à la balise du formulaire pour indiquer à Turbo que le formulaire est lié au turbo-frame ciblé par `data-turbo-frame` :
```html
<!-- Mon formulaire est en dehors du turbo-frame ! MAIS JE PRECISE LE TURBO-FRAME CIBLE -->
<form action="{{path('app_dashboard')}}" data-turbo-frame="taskfiltered">
    <!--  -->
</form>
<!-- Le contenu que je veux uniquement recharger -->
<turbo-frame id="taskfiltered" >
    <div class="container">
        {% for task in tasks %}
        <div>
            <p>tache {{ task.id }}</p>
        </div>
        <div>
            <p>tache {{ task.id }}</p>
        </div>
        {% endfor %}
    </div>
</turbo-frame>
```

### Autre exemple la pagination avec Turbo
Ici vous pouvez voir un système de pagination qui recharge uniquement la liste des tâches sans recharger toute la page grâce à Turbo :
```html
<nav>
  <a href="/profil" data-turbo-frame="main_content">Voir le profil</a>
  <a href="/parametres" data-turbo-frame="main_content">Voir les paramètres</a>
</nav>

<turbo-frame id="main_content">
  <p>Le contenu apparaîtra ici après le clic.</p>
</turbo-frame>
```

1. Il va chercher la page ciblé la lien (il doit contenir un turbo-frame avec l'id "main_content" pour que ça fonctionne)
2. Puis si il y a bien un turbo-frame avec l'id "main_content", il va remplacer que le contenu du turbo-frame ciblé par le nouveau contenu récupéré.

> Attention il faut que la page ciblé par le lien contienne un turbo-frame avec l'id "main_content" pour que ça fonctionne.
