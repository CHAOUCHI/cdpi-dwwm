
- Pour faire des messages type notification qui s'affichent en bas à froite de l'écran, on peut utiliser les flash messages de Symfony.

- Afficher un message après la soumission d'un formulaire sur la même page est facile il suffit de déclarer une variable, la passé à la vue, le soucis c'est que si on redirige vers une autre page, la variable ne sera plus disponible. Et après une action réussi comme une deconnexion,une soumission de formulaire, on redirige souvent vers une autre page. C'est là que les flash messages sont utiles, ils permettent de stocker un message dans la session qui sera disponible sur la page suivante car, je le rappel, les variables de session sont disponibles sur toutes les pages du site.

1. Dans le fichier *base.html.twig* on ajoute le code suivant pour afficher des messages flashes statiques en HTML/CSS:
```html
<div class="notif_container flex flex-col gap-8 fixed bottom-3 right-5 ">
    <div class="notif bg-red-300 border p-3">
        <p>Une petite notif cool !</p>
    </div>
</div>
```
2. Utilisez la méthode membre ***`setFlash(array arrayName,string strtoPushInto)`*** dans un Controller :
```php
<?php
/// use ..

class ExempleController{

    #[Route(name:"app_index")]
    public function index() : Response
    {

        // du code qui fait des trucs comme ajouter un produit à la base de données ou envoyer un mail.
        // +
        $this->setFlash("notif","Produit ajouté avec succes !");
        $this->setFlash("notif","2eme messages de succès");

        return $this->render('exemple/index.html.twig')
    }
}
```

La méthode membre setFlash du Controller `push` une string dans un tableau de string accessible depuis n'importe quelle page, car les messages flashes sont stocké dans la *SESSION*, et je rappelle que les variables stocké dans `$_SESSION` sont accessible depuis toutes les pages du site en PHP. (cf. Phase1)

J'ai push des notifs, maintenant je vais : 

1. modifier le fichier `base.html.twig` pour le rendre dynamique en affichant le tableau de flashes avec la méthode `app.flashes()` dont voici la définition :

```php

// ... lit la session et retourne le tableau de string rempli par son homologue addFlash()
function flashes(string arrayName) : array
```

*base.html.twig*
```html
<div class="notif_container flex flex-col gap-8 fixed bottom-3 right-5 ">
    {% for message in app.flashes("notif") %}
    <div class="notif bg-red-300 border p-3">
        <p>{{ message }}</p>
    </div>
    {% endfor %}
</div>
```
