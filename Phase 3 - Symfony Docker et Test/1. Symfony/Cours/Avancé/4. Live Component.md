
# Live Component

## Résumé
*Les PHP attributs à retenir*
- `#[LiveProp(writable: true)]` pour définir un attribut public de la classe comme une propriété du composant qui peut être modifiée depuis le client.
- `#[LiveAction]` pour définir une méthode de la classe comme une action(fonction appellée par un *event* du DOM) du composant qui peut être déclenchée depuis le client.


```php
<?php

#[AsLiveComponent]
class MyLiveComponent extends LiveComponent
{
    use D..;

    #[LiveProp(writable: true)]
    public string $searchTxt = '';

}
```

*Twig HTML attribut*
Utilisez *data-model* pour synchroniser une *LiveProp* et un *input* HTML :
```html
{% block body %}
<input type="text" data-model="livePropName">
<p>{{ searchTxt }}</p> {# Affiche la valeur de searchTxt en temps réel #}
{% endblock %}
```

1. Testez votre composant en tapant du texte dans le champ de recherche. Vous devriez voir la valeur de `searchTxt` mise à jour en temps réel.

## Comment ça marche ?
A chaque fois que vous tapez une lettre :
1. L'evenement change est déclenché sur l'input
2. Symfony déclancher l'envoie d'une requête fetch le serveur
3. Le fetch contient la nouvelle valeur de `searchTxt`
4. Symfony met à jour la propriété `searchTxt` du composant avec la nouvelle valeur
5. Symfony re-calcul le HTML du composant et renvoie le HTML mis à jour au client

> Pour se rendre compte des fetchs envoyés au serveur, ouvrez les outils de développement de votre navigateur (F12), allez dans l'onglet "Network" et observez les requêtes qui sont envoyées à chaque fois que vous interagissez avec le composant.

## Ecouter un evenement du DOM Exemple du Clicker (incrementer on click)

> ***Résumé***
> - **Ecouter un évenement** sur un balise input : `data-action="click->live#action"` ou `live-action="submit->live#action"` donc `live-action="eventName->live#action"`
> - **Définir une méthode callblack pour cet event** (à placer sur la même balise input): `data-live-action-param="nomDeLaFonctionPHP"`


Avec les live components il est aussi possible d'écouter un evenement du DOM comme en React et de déclencher une fonction PHP coté serveur. C'est un gros avantage car on n'a pas besoin d'ecrire une api rest et du javascript pour faire le rendu Symfony s'occupe de tout.

1. Il suffit d'ajouter l'attribut HTML `data-action` à l'element du DOM que l'on veut écouter :
```html
{% block body %}
<button data-action="click->live#action">Click me !</button>
<p>{{nbClick}}</p> {# Affichera le nombre de click #}
{% endblock %}
```

2. Puis l'attribut `data-live-action-param` pour spécifier la fonction PHP à appeler :
```html
{% block body %}
<button data-action="click->live#action" data-live-action-param="increment">Click me !</button>
<p>{{nbClick}}</p> {# Affichera le nombre de click #}
{% endblock %}
```

Ici je souhaite compter le nombre de clique sur le bouton, il me faut donc un *LiveProp* *nbClick* à afficher et incrémenter à chaque clique.

3. Et donc évidemment définir la fonction PHP dans le composant, en précisant **le PHP attribut #[LiveAction]** avant la méthode pour la définir comme une action possible du live component :
```php
<?php

#[AsLiveComponent]
class MyLiveComponent extends LiveComponent
{
    use D..;

    #[LiveProp(writable: true)]
    public int $nbClick = 0;

    // + le PHP attribut #[LiveAction] pour définir la méthode comme une action du composant
    // la méthode doit être de type void et ne pas prendre de paramètre
    // Cette méthode augementer la valeur du LiveProp nbClick et donc déclenche une mise à jour de la vue.
    #[LiveAction]
    public function increment(): void
    {
        $this->nbClick++;
    }
}
```

> La méthode *increment* augemente la valeur du LiveProp nbClick et donc déclenche une mise à jour de la vue.


## Ecouter un evenement du DOM Exemple du Scroll (incrementer on scroll)
```html
{% block body %}
<div class="h-40 overflow-scroll " data-action="scroll->live#action" data-live-action-param="increment">
    {% for i in 0..100 %}
        <p>Scroll me to increment !</p>
    {% endfor %}
</div>
{% endblock %}
```
