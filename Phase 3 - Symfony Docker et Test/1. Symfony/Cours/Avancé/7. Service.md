# Service Symfony

En programmation orientée objet, un service est une simple classe qui effectue une tâche spécifique sans representer un objet métier de l'application. Un service est généralement utilisé pour encapsuler une logique métier ou une fonctionnalité réutilisable dans l'application, comme l'envoi d'emails, la génération de PDF, la gestion des formulaires, etc.

> Vous devez créer un service si vous voulez encapluser votre code dans des fonctions
