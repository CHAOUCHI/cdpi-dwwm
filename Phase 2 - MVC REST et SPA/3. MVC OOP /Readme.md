# Plan d'action

Dans ce module, vous apprendrez à organiser correctement votre code back-end grâce au patron de conception (Design Pattern) MVC (Model View Controller).

## 1. Cours
Il s'agit d'un cours/TP qu'il vous suffit de suivre pas à pas en effectuant les exercices au fur et à mesure.

À la fin, vous aurez conçu un mini framework MVC en PHP, une compétence que vous apprécierez grandement pour conquérir les frameworks back-end comme Symfony, Laravel ou Spring (Java).

## 2. Projet
Un projet Allociné où vous devez concevoir une application web qui permet d'ajouter des films à l'affiche et de programmer leurs horaires de diffusion en salle.

Rien de bien compliqué :
- Une table de `Films`
- Une table de `Diffusions`
- Une relation OneToMany entre les deux pour associer des diffusions à un film.
