
# Sprint timeline

Voici l'emploi du temps d'une semaine agile Scrum.

Vous devez représenter ce planning chaque semaine : c'est la boucle de la méthode Scrum.

| Journée   |                           |                   |
|-----------|---------------------------------------------|-----------------------------------------|
| Lundi     | (9h-11h) Sprint Planning (2h max)           | (9h-9h15) Daily Scrum (15 min)          |
| Mardi     |                                             | (9h-9h15) Daily Scrum (15 min)          |
| Mercredi  |                                             | (9h-9h15) Daily Scrum (15 min)          |
| Jeudi     |                                             | (9h-9h15) Daily Scrum (15 min)          |
| Vendredi  | (15h45-16h45) Sprint Review (1h max)        | (9h-9h15) Daily Scrum (15 min)          |

- **Daily Scrum** : A pour objectif de vérifier pour chaque personne si la tâche qui lui est attribuée depuis le backlog (GitHub Project) pose des difficultés ou si elle est terminée.
- **Sprint Planning** : Définit les tâches à effectuer (le backlog).
- **Sprint Review** : Place les tâches non finies dans le backlog de la semaine prochaine et discute des difficultés rencontrées cette semaine.
