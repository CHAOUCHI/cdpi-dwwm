
## Créer un composant
La création d'un composant doit se faire dans un fichier à part qui porte le nom du composant.

Placez le composant racine `<App>` dans un autre fichier nommé App.jsx.
```jsx
function App(){
    return (
        <h1>Hello App</h1>
    );
}
```
Exportez-le avec le mot-clé `export`.
```jsx
export function App(){
    return (
        <h1>Hello App</h1>
    )
}
```
Importez la fonction App dans le fichier main.jsx.
```jsx
import React from "react";
import ReactDOM from "react-dom/client";

import {App} from "./App";      // Import du composant App

const root = ReactDOM.createRoot(document.querySelector("#root"));
root.render(<App/>);            // Appel du composant App
```
Au minimum un composant est une fonction qui renvoie du JSX.
```jsx
function NomDuComposant(){
    /**
     * Code éventuel
     * */
    return (
        // JSX
    );
}
```

Voici par exemple un composant Eleve qui affiche les informations d'un élève.

```jsx
function Eleve()
{
    const prenom = "Massinissa";
    const nom = "CHAOUCHI";
    const age = 24;
    return (
        <div>
            <h2>{nom}</h2>
            <p>{prenom}</p>
            <p>{age} ans</p>
        </div>
    );
}
```

### Importer du CSS

Vous pouvez importer un fichier css avec le mot clé `import` :

1. Créer un fichier Eleve.css

*Eleve.css*
```css
.eleve{
    background-color: purple;
}
```
2. Importer Eleve.css

```jsx

import './Eleve.css';

function Eleve()
{
    const prenom = "Massinissa";
    const nom = "CHAOUCHI";
    const age = 24;
    return (
        <div className="eleve">
            <h2>{nom}</h2>
            <p>{prenom}</p>
            <p>{age} ans</p>
        </div>
    );
}
```

### L'attribut style


L'attribut `style` en React accepte un objet JavaScript contenant des propriétés CSS en camelCase plutôt qu'une chaîne de caractères comme en HTML classique.

**Syntaxe**
```jsx
<div style={{ propriété: 'valeur' }}>Contenu</div>
```

**Exemple simple**
```jsx
function Eleve() {
    return (
        <div style={{ backgroundColor: 'purple', color: 'white', padding: '20px' }}>
            <h2>CHAOUCHI</h2>
            <p>Massinissa</p>
        </div>
    );
}
```

**Avec une variable**
```jsx
function Eleve() {
    const styles = {
        backgroundColor: 'purple',
        color: 'white',
        padding: '20px',
        borderRadius: '10px'
    };
    
    return (
        <div style={styles}>
            <h2>CHAOUCHI</h2>
            <p>Massinissa</p>
        </div>
    );
}
```

> **Note** : Les propriétés CSS avec des tirets (comme `background-color`) deviennent des propriétés camelCase (`backgroundColor`) en JavaScript.
