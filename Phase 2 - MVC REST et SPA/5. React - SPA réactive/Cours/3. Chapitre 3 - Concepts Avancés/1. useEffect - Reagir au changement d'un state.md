## `useEffect`  réaction au changement d’un `state`

L’hook `useEffect` dans React est utilisé pour effectuer des effets secondaires dans les composants fonctionnels. L'un de ses cas d'utilisation est lorsque nous voulons effectuer une action ou mettre à jour quelque chose quand un état particulier change.

#### Syntaxe
```jsx
useEffect(() => {
  // Action à effectuer
}, [dépendances]);
```

- L'effet s'exécute lorsqu'une des **dépendances** dans le tableau change de valeur.

---

#### Exemple 1 : Mettre à jour un état basé sur un autre
```jsx
import React, { useState, useEffect } from 'react';

function Example1() {
  const [count, setCount] = useState(0);
  const [doubleCount, setDoubleCount] = useState(0);

  useEffect(() => {
    setDoubleCount(count * 2); // Double le count
  }, [count]); // Exécuté uniquement quand `count` change

  return (
    <div>
      <p>Compteur : {count}</p>
      <p>Double : {doubleCount}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrementer
      </button>
    </div>
  );
}
```

---

#### Exemple 2 : Déclencher une mise à jour visuelle
```jsx
import React, { useState, useEffect } from 'react';

function Example2() {
  const [color, setColor] = useState('rouge');
  const [bgColor, setBgColor] = useState('');

  useEffect(() => {
    setBgColor(color === 'rouge' ? 'red' : 'blue');
  }, [color]);

  return (
    <div style={{ backgroundColor: bgColor, padding: '20px' }}>
      <p>Couleur actuelle : {color}</p>
      <button onClick={() => setColor(color === 'rouge' ? 'bleu' : 'rouge')}>
        Changer la Couleur
      </button>
    </div>
  );
}
```

---

#### Exemple 3 : Appel d’une API lorsque l'état change
```jsx
import React, { useState, useEffect } from 'react';

function Example3() {
  const [searchTerm, setSearchTerm] = useState('');
  const [results, setResults] = useState([]);

  useEffect(() => {
    if (searchTerm) {
      fetch(`https://api.example.com/search?q=${searchTerm}`)
        .then((response) => response.json())
        .then((data) => setResults(data.results));
    }
  }, [searchTerm]); // Appel API chaque fois que searchTerm change

  return (
    <div>
      <input
        type="text"
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
      />
      <ul>
        {results.map((result, index) => (
          <li key={index}>{result.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

---

### Points clés à retenir sur `useEffect`
1. **Exécution initiale** : Si aucun tableau de dépendances n'est fourni, l'effet s'exécute après chaque rendu.
2. **Dépendances** : Spécifiez les states dans le tableau pour restreindre quand l'effet doit être exécuté.
