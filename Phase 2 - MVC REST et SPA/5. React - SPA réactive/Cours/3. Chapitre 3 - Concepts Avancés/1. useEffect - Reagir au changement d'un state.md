## `useEffect`  réaction au changement d’un `state`

Le hook `useEffect` dans React est utilisé pour effectuer des effets secondaires dans les composants. L'un de ses cas d'utilisation est lorsque nous voulons effectuer une action ou mettre à jour quelque chose quand un état particulier change.

Concrètement, `useEffect` permet de modifier un state à chaque fois qu'un autre state est mis à jour.


#### Syntaxe
```jsx

const [stateA, setStateA] = useState(initialValue);

useEffect(() => {
  // Action à effectuer A CHAQUE FOIS que stateA change
}, [stateA]); // Tableau de dépendances
```

- L'effet s'exécute lorsqu'une des **dépendances** dans le tableau change de valeur.

---

#### Exemple 1 : Multiplier un compteur par 2
Ici on peut voir que :
- Le state `doubleCount` est mis à jour (`setDoubleCount`) à chaque fois que le state `count` change.

```jsx
import React, { useState, useEffect } from 'react';

function Example1() {
  const [count, setCount] = useState(0);
  const [doubleCount, setDoubleCount] = useState(0);

  useEffect(() => {
    setDoubleCount(count * 2); // Double le count
  }, [count]); // Exécuté uniquement quand `count` change

  return (
    <div>
      <p>Compteur : {count}</p>
      <p>Double : {doubleCount}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrementer
      </button>
    </div>
  );
}
```


#### Exemple 2 : Appel d’une API lorsque l'état change

Ici je veux effectuer un fetch à chaque fois que l'utilisateur tape des données dans une barre de recherche.

Donc :
- Le state `searchInput` est mis à jour à chaque fois que l'utilisateur tape dans l'input grâce à l'evenement `onChange`.
- Le state `results` est mis à jour à chaque fois que `searchInput` change, grâce à `useEffect` qui effectue un fetch vers une API externe et `setResults` avec les résultats reçus.



```jsx
import React, { useState, useEffect } from 'react';

function Example3() {
  const [searchInput, setSearchTerm] = useState('');
  const [results, setResults] = useState([]);

  useEffect(() => {
    if (searchInput) {
      fetch(`https://pokebuildapi.fr/api/v1/pokemon/${searchInput}`)
        .then((response) => response.json())
        .then((pokemons) => setResults(pokemons));
    }
  }, [searchInput]); // Appel API chaque fois que searchInput change

  return (
    <div>
      <input
        type="text"
        onChange={(e) => setSearchTerm(e.target.value)}
      />
      <ul>
        {results.map((result, index) => (
          <li key={index}>{result.name}</li>
        ))}
      </ul>
    </div>
  );
}
```

#### Exemple 3 : Déclencher une mise à jour visuelle
```jsx
import React, { useState, useEffect } from 'react';

function Example2() {
  const [color, setColor] = useState('rouge');
  const [bgColor, setBgColor] = useState('');

  useEffect(() => {
    setBgColor(color === 'rouge' ? 'red' : 'blue');
  }, [color]);

  return (
    <div style={{ backgroundColor: bgColor, padding: '20px' }}>
      <p>Couleur actuelle : {color}</p>
      <button onClick={() => setColor(color === 'rouge' ? 'bleu' : 'rouge')}>
        Changer la Couleur
      </button>
    </div>
  );
}
```

### Points clés à retenir sur `useEffect`
1. **Exécution initiale** : Si aucun tableau de dépendances n'est fourni, l'effet s'exécute après chaque rendu.
2. **Dépendances** : Spécifiez les states dans le tableau pour restreindre quand l'effet doit être exécuté.
