
## Props - Paramétrer un composant
Les props sont les attributs paramétrables des composants JSX que vous créez.

L'intérêt des composants est la modularité, un composant a pour objectif d'être réutilisé dans des contextes différents et se doit donc d'être paramétrable.

Les props d'un composant sont définies en paramètre de sa fonction et on définit leurs valeurs à l'appel du composant à la manière du HTML.

```jsx
export function Eleve({prenom, nom, age})
{
    return (
        <div>
            <h2>{nom}</h2>
            <p>{prenom}</p>
            <p>{age} ans</p>
            <p>{ age>=18 ? "Majeur" : "Mineur" }</p>
        </div>
    );
}
```

```jsx
import {Eleve} from "./Eleve";
export function App(){
    return (
        <>
            <Eleve prenom="Massinissa" nom="CHAOUCHI" age={24}/>
            <Eleve prenom="Louis" nom="BERGER" age={25}/>
        </>
    );
}
```
Le JSX utilise une syntaxe proche de celle des attributs HTML mais en réalité le JSX passe simplement un objet en paramètre de la fonction.

Ces deux lignes produisent le même résultat.
```jsx
<Eleve prenom="Massinissa" nom="CHAOUCHI" age={24}/>
Eleve({
    prenom : "Massinissa",
    nom : "CHAOUCHI",
    age : 24
});
```

> Étant donné que la fonction prend un objet en paramètre il faut utiliser le `destructuring assignment` pour accéder aux props dans la fonction.
>```jsx
>export function Eleve({prenom, nom, age})
>```
