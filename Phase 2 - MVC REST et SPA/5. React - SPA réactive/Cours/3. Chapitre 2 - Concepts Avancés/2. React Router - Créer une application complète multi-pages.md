# Créer un projet React avec Vite et React Router — Cours rapide

## 1. Créer le projet
- Initialiser :
```bash
npm create vite@latest mon-app -- --template react
cd mon-app
npm install
npm install react-router-dom
npm run dev
```
- Alternative (pnpm / yarn) : remplacer la commande d'install/launch.

## 2. Résumé de l'arborescence (exemple minimal)
```
mon-app/
├─ index.html
├─ package.json
├─ src/
│  ├─ main.jsx        # point d'entrée (BrowserRouter / RouterProvider)
│  ├─ App.jsx         # optionnel, wrapper d'app
│  ├─ routes.jsx      # (conseillé) définition des routes
│  ├─ pages/
│  │  ├─ Home.jsx
│  │  ├─ About.jsx
│  │  ├─ Login.jsx
│  │  └─ NotFound.jsx
│  └─ components/
│     └─ RequireAuth.jsx
```

## 3. Où sont définies nos routes ?
- Les routes sont définies côté client dans le code React. On les place généralement :
    - directement dans `src/main.jsx` (petites apps), ou
    - dans un fichier `src/routes.jsx` puis importé dans `main.jsx`.
- Deux approches courantes : JSX `<BrowserRouter><Routes>...</Routes></BrowserRouter>` ou API `createBrowserRouter` + `RouterProvider`.

La création des routes se fait en modifant la balise render par le kernel de react dans `src/main.jsx`.

- Il faut Appeller la balise `<BrowserRouter>` qui va englober toutes les routes de l'application.
```jsx
// src/main.jsx
import { createRoot } from 'react-dom/client'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Home from './pages/Home'
import About from './pages/About'
import NotFound from './pages/NotFound'

createRoot(document.getElementById('root')).render(
    <BrowserRouter>
        
    </BrowserRouter>
)
```
- Ensuite on utilise la balise `<Routes>` qui va contenir toutes les routes de l'application.
```jsx
// src/main.jsx
import { createRoot } from 'react-dom/client'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Home from './pages/Home'
import About from './pages/About'
import NotFound from './pages/NotFound'

createRoot(document.getElementById('root')).render(
    <BrowserRouter>
        <Routes>
            
        </Routes>
    </BrowserRouter>
)
```
- Chaque route est définie avec la balise `<Route>` qui prend en props :
    - `path` : le chemin de la route
    - `element` : le composant React à afficher pour cette route
```jsx
// src/main.jsx
import { createRoot } from 'react-dom/client'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Home from './pages/Home'
import About from './pages/About'
import NotFound from './pages/NotFound'

createRoot(document.getElementById('root')).render(
    <BrowserRouter>
        <Routes>
            <Route path="/" element={<Home/>}/> // Page d'accueil
            <Route path="/about" element={<About/>}/> // Page à propos
            <Route path="*" element={<NotFound/>}/> // Page 404
        </Routes>
    </BrowserRouter>
)
```

## 4. Navigation entre les pages
1. Lancer le serveur de dev
```bash
npm run dev
```

2. Créer les pages
- Créer les composants React pour chaque page dans `src/pages/` :
    - Home.jsx,
    - About.jsx,
    - NotFound.jsx

3. Naviguer entre les pages
La balise Link de react-router-dom permet de créer des liens de navigation entre les pages sans recharger la page entière (Single Page Application). C'est une surcouche de la balise `<a>` classique qui utilise l'API History de HTML5 pour changer l'URL sans recharger la page.


4. Créez un composant Navbar pour la navigation et utilisez la balise `<Link>` de `react-router-dom` pour créer des liens de navigation

```jsx
import { Link } from 'react-router-dom';
function Navbar() {
    return (
        <nav>
            <Link to="/">Accueil</Link>
            <Link to="/about">À propos</Link>
        </nav>
    );
}
```

5. Ajoutez le composant Navbar dans `src/main.jsx` pour qu'il soit visible sur toutes les pages

```jsx
// src/main.jsx
import { createRoot } from 'react-dom/client'
import { BrowserRouter, Routes, Route } from 'react-router-dom'
import Home from './pages/Home'
import About from './pages/About'
import NotFound from './pages/NotFound'

createRoot(document.getElementById('root')).render(
    <BrowserRouter>
        <Navbar />
        <Routes>
            <Route path="/" element={<Home/>}/> // Page d'accueil
            <Route path="/about" element={<About/>}/> // Page à propos
            <Route path="*" element={<NotFound/>}/> // Page 404
        </Routes>
    </BrowserRouter>
)
```

6. Naviguez entre les pages en cliquant sur les liens de la navbar.

## 4. Comment ajouter une route ?
1. Créer un composant React pour cette nouvelle page dans `src/pages/`, par exemple `Contact.jsx`.
```jsx
// src/pages/Contact.jsx
export default function Contact() {
    return <h1>Page de contact</h1>;
}
```
2. Importer ce composant dans `src/main.jsx`.
```jsx
import Contact from './pages/Contact';
```
3. Ajouter une nouvelle balise `<Route>` dans `<Routes>` pour définir le chemin et le composant à afficher.
```jsx
<Routes>
    <Route path="/" element={<Home/>}/>
    <Route path="/about" element={<About/>}/>
    <Route path="*" element={<NotFound/>}/>
    // ++-- Nouvelle route --
    <Route path="/contact" element={<Contact/>}/>
</Routes>
```
> Syntaxe : Dans la balise `<Routes>` : ajouter une balise `<Route path="/chemin/vers" element={<MonComponent/>} />`.

## 6. Page 404
Utilisez la route wildcard `*` pour capturer toutes les routes non définies.
```jsx
<Route path="*" element={<NotFound/>} />
```
