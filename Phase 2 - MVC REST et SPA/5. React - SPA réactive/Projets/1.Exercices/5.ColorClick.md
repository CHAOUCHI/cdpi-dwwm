# Exercice ColorClick
Un Composant qui permet de modifier les propriété backgroundColor et color d'un Article de blog avec des options cliquable.

## Démo
Rendez-vous sur : http://whiletrue.fr:8080

ou lancez le container dopcker suivant :
```bash
docker run -p 8080:80 chaouchi/react-exo-usestate
```
