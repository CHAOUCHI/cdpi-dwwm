# Les attributs HTML

## Lire la valeur d'un attribut HTML

Pour lire la valeur de n'importe quel attribut HTML, on utilise la méthode `getAttribute` sur un `Element`.  
> Pour rappel, les éléments sont des objets retournés par la méthode `querySelector`.

```html
<img src="pigeon.png" alt="une image de pigeon">
<p class="text-content font-14">Some text</p>
<a href="https://youtube.com">Clique-moi</a>
<input id="name" value="Écrire ici le nom...">
<personnage pv="100">
```

```js
const imgTag_elem = document.querySelector("img");
const lienDeImage_str = imgTag_elem.getAttribute("src");     // "pigeon.png"

const pTag_elem = document.querySelector("p");
const classNames_str = pTag_elem.getAttribute("class");      // "text-content font-14"

const linkTag_elem = document.querySelector("a");
const link_str = linkTag_elem.getAttribute("href");          // "https://youtube.com"

const inputTag_elem = document.querySelector("#name");
const input_str = inputTag_elem.getAttribute("value");       // "Écrire ici le nom..."

const persoTag_elem = document.querySelector("personnage");
const pv_str = persoTag_elem.getAttribute("pv");             // "100"
```

## Modifier la valeur d'un attribut HTML

La valeur d'un attribut se modifie avec la méthode `setAttribute` de la classe `Element`.

```js
const imgTag_elem = document.querySelector("img");

let lienDeImage_str = imgTag_elem.getAttribute("src");     
console.log(lienDeImage_str);       // => "pigeon.png"

// Modification d'attributs HTML
imgTag_elem.setAttribute("src", "aigle.png");
imgTag_elem.setAttribute("alt", "Photo d'un aigle");

lienDeImage_str = imgTag_elem.getAttribute("src");     
console.log(lienDeImage_str);      // => "aigle.png"
```

## L'attribut `class`

Les classes CSS peuvent être modifiées via la méthode `setAttribute`. Le problème est que cette méthode renvoie une `string` de toutes les classes CSS et rend par conséquent laborieuse la suppression ou l'ajout d'une classe, ce qui est pourtant une tâche courante en JavaScript front-end.

Voilà pourquoi on préfère l'utilisation de l'objet `Element.classList` et de ses méthodes : `add`, `remove` et `toggle`.

*index.html*
```html
<p class="text-content font-14">Some text</p>
```

### Supprimer une classe CSS - `Element.classList.remove`

```js
// On retire la classe font-14
paraTag_elem.classList.remove("font-14");
```

Résultat  
*index.html*
```html
<p class="text-content">Some text</p>
```

### Ajouter une classe CSS - `Element.classList.add`

```js
// On ajoute la classe font-6
paraTag_elem.classList.add("font-6");
```

*index.html*
```html
<p class="text-content font-14 font-6">Some text</p>
```

### Inverser la présence d'une classe CSS - `Element.classList.toggle`
Parfois, vous voulez inverser la présence d'une classe CSS, par exemple pour activer ou désactiver une classe `darkmode`.

À la façon d'un interrupteur électrique, `Element.classList.toggle` permet de changer l'état d'une classe : présente ou non.

```js
// On inverse la présence de la classe text-content
paraTag_elem.classList.toggle("text-content");               
console.log(paraTag_elem.getAttribute("class"));     // => "font-6"

// On inverse la présence de la classe text-content
paraTag_elem.classList.toggle("text-content");               
console.log(paraTag_elem.getAttribute("class"));     // => "font-6 text-content"
```

> Souvenez-vous de `toggle` pour coder un menu burger, un bouton darkmode ou n'importe quel menu déroulant.

## L'attribut `style`

Comme l'attribut `class`, l'attribut `style` est difficile à traiter avec la méthode `Element.setAttribute`.

```html
<h1 style="font-size:16px;color:#efefef;margin:5px;">Bienvenue chez nous !</h1>
```

Comment gérer toutes ces règles CSS contenues en une seule et même chaîne de caractères ?  
La solution est l'objet `Element.style` et ses attributs.

### L'objet `Element.style`

L'objet `style` possède toutes les règles CSS sous forme d'attributs.  
Si je souhaite modifier la règle `font-size` à `20px` de mon `<h1>`, je fais :

```js
const h1_elem = document.querySelector("h1");
h1_elem.style.fontSize = "20px";
```

> **Combien de règles CSS sont prises en compte ?**  
> Si vous souhaitez voir l'ensemble des règles CSS disponibles dans l'objet `Element.style`, effectuez un `console.log(h1_elem.style)` pour que le navigateur vous affiche les attributs de l'objet `style`. (Firefox)

> **Le CamelCase**  
> La syntaxe des règles CSS est en **camelCase**, c'est-à-dire la **première lettre en minuscule** puis chaque **début de mot en majuscule**. C'est également la syntaxe de référence de tout code écrit en JS.
