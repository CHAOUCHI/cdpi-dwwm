# Cas d'utilisation commun
Ici je décris des cas d'utilisation communs du DOM et de l'api Fetch dans le cadre d'une application SPA.
> SPA : Single Page Application. Une application web qui charge une seule page HTML et met à jour dynamiquement le contenu au fur et à mesure que l'utilisateur interagit avec l'application grâce au JavaScript et à la fonction fetch (un client http).

## Créer un élément proprement - Orientée composant
> Rappel : un élément est une balise HTML.

Ici je vais vous montrer une façon propre de créer des élements HTML.

Le principe est simple :
- Je crée une fonction qui `return` un élément HTML 
- Cette fonction prend en paramètre les données nécessaires à la création de l'élément HTML ( souvent les données d'un objet provenant d'une table SQL)
- Je me se
```html
<button class="btn_add">Ajouter un élément</button>
<div class="container">

</div>
``` 

```js
const btnAdd = document.querySelector('.btn_add');
const container = document.querySelector('.container');

btnAdd.addEventListener('click', () => {
    const productElement = ProductElement('Nike', 100);
    container.appendChild(productElement);
});

/*
Retourne un élément HTML représentant un produit
@param {string} name
@param {number} price
@returns {HTMLElement}
*/
function ProductElement(name, price) {
    // <div></div>
    const productElement = document.createElement('div');
    // <div class="product"></div>
    productElement.classList.add('product');

    // <h2>name</h2>
    const nameElement = document.createElement('h2');
    nameElement.textContent = name;

    // <p>price</p>
    const priceElement = document.createElement('p');
    priceElement.textContent = price;

    // <div class="product">
    //      <h2>name</h2>
    //      <p>price</p>
    // </div>
    productElement.appendChild(nameElement);
    productElement.appendChild(priceElement);

    return productElement;
}
```

## Créer un élement à partir d'un formulaire (orientée composant)
Pour créer un élément à partir d'un formulaire, on suit la même logique orientée composant, mais cette fois on récupère les données saisies par l'utilisateur dans le formulaire.

```html
<form class="product-form">
    <input type="text" name="name" placeholder="Nom du produit" required>
    <input type="number" name="price" placeholder="Prix" required>
    <button type="submit">Ajouter</button>
</form>
<div class="container"></div>
```

```js
const form = document.querySelector('.product-form');
const container = document.querySelector('.container');

form.addEventListener('submit', (e) => {
    e.preventDefault();
    const formData = new FormData(e.target);
    const name = formData.get('name');
    const price = formData.get('price');
    const productElement = ProductElement(name, price);
    container.appendChild(productElement);
    form.reset();
});
```

Ici, la fonction `ProductElement` est réutilisée pour générer l'affichage du produit à partir des valeurs du formulaire.

> Attention ! La fonction `ProductElement` n'affiche pas la balise à l'écran ! Elle retourne simplement une variable de type `HTMLElement` que l'on peut ensuite insérer dans le DOM avec `appendChild`.

## Récupérer des données via un fetch et les afficher dans une liste (orientée composant)
Pour afficher une liste de Pokémon récupérés via l'API PokéBuildAPI, on peut utiliser `fetch` pour obtenir un tableau de Pokémon, puis utiliser `forEach` pour créer un composant pour chaque Pokémon.

```html
<button class="load-pokemons">Charger les Pokémons</button>
<div class="pokemons-list"></div>
```

```js
const btnLoad = document.querySelector('.load-pokemons');
const listContainer = document.querySelector('.pokemons-list');

btnLoad.addEventListener('click', async () => {
    const response = await fetch('https://pokebuildapi.fr/api/v1/pokemon/limit/10');
    if (response.ok) {
        const pokemons = await response.json();
        pokemons.forEach(pokemon => {
            const pokemonComponent = PokemonComponent(pokemon.name, pokemon.image);
            listContainer.appendChild(pokemonComponent);
        });
    } else {
        listContainer.innerHTML = '<p>Erreur lors du chargement des Pokémons.</p>';
    }
});

/*
Retourne un élément HTML représentant un Pokémon (composant)
@param {string} name
@param {string} image
@returns {HTMLElement}
*/
function PokemonComponent(name, image) {
    const pokemonElement = document.createElement('div');
    pokemonElement.classList.add('pokemon');

    const nameElement = document.createElement('h3');
    nameElement.textContent = name;

    const imgElement = document.createElement('img');
    imgElement.src = image;
    imgElement.alt = name;

    pokemonElement.appendChild(nameElement);
    pokemonElement.appendChild(imgElement);

    return pokemonElement;
}
```

Dans cet exemple, chaque Pokémon de la liste est affiché grâce à la fonction `PokemonComponent`, appelée dans un `forEach` sur le tableau retourné par l'API.

## data-* pour identifier un élement de façon unique via son pokeid quand je clique dessus je console.log ses infos via un fetch et un get data-id

Une fois les éléments crées comment faire pour définir qu'un élément correspond à un objet en particulier ?

Stocker son id (souvent la primary key en base de donnée) dans le HTML de l'élément !

Pour faire ça je peux utiliser l'attribut `data-*` qui permet de stocker des données personnalisées dans une balise HTML.

*exemple fonctionnement data-**
```html
<div class="pokemon" data-id="1">
    <h3>Pikachu</h3>
    <img src="https://img.pokemondb.net/sprites/home/normal/pikachu.png" alt="Pikachu">
</div>
<script>
    const pokemonElement = document.querySelector('.pokemon');
    console.log(pokemonElement.dataset.id); // Affiche "1"
</script>
```
