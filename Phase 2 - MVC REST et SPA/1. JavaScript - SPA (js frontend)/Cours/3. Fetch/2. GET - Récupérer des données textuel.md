# GET - Récupérer des données avec fetch

La fonction `fetch()` permet de récupérer des données d'un serveur. Concrètement, fetch est un **client HTTP** : il permet donc d'**effectuer une requête HTTP**.

## Pré-requis - un serveur HTTP
La destination d'une requête HTTP est un serveur HTTP. Il nous en faut donc un.

1. Créez un fichier `server.js` et copiez-collez le code suivant.

Ne vous attardez pas sur le fonctionnement du serveur, vous apprendrez son fonctionnement dans le module NodeJS.

Sachez seulement qu'il est accessible via l'origine :

`http://localhost:8080`

Et qu'il possède trois routes possibles (URLs) :

- `/` : renvoie la string `abcd` au client.
- `/hello-text` : renvoie la string `Hello World !` au client.
- `/fruits-json` : renvoie également une string au client. Cette string est un tableau JavaScript formaté au format JSON.

*server.js*
```js
import http from "http";

const PORT_number = 8080;
const IP_str = "0.0.0.0";

const server_obj = http.createServer((req_obj, res_obj) => {
    // Si le serveur et le client n'ont pas la même origine
    // (si un client fetch sur le port 3000 fetch notre serveur port 8080)
    if (req_obj.headers.origin !== undefined) {
        console.log("request header - Origin : ", req_obj.headers.origin);
        res_obj.setHeader("Access-Control-Allow-Origin", req_obj.headers.origin);
        console.log("response header - Access-Control-Allow-Origin : ", res_obj.getHeader("Access-Control-Allow-Origin"));
    }

    // J'écris une réponse HTTP en fonction de l'URL
    let body_str = "";
    switch (req_obj.url) {
        case "/":
            body_str = "abcd";
            res_obj.write(body_str);
            break;
        case "/hello-text":
            body_str = "Hello World !\n";
            res_obj.write(body_str);
            break;
        case "/fruits-json":
            const fruits_arr = [
                { name: "pomme", price: 3 },
                { name: "cassis", price: 8 },
                { name: "framboise", price: 7 },
            ];
            body_str = JSON.stringify(fruits_arr);
            res_obj.setHeader("Content-type", "application/json");
            res_obj.write(body_str);
            break;
        default:
            res_obj.statusCode = 404;
            res_obj.write("Not Found");
            break;
    }

    // Terminer la connexion (Envoie la réponse au client)
    res_obj.end();
});

server_obj.listen(PORT_number, IP_str, () => {
    console.log(`Server starts on ${IP_str}:${PORT_number}`);
});
```

2. Lancez le serveur HTTP avec la commande `node` :

```bash
node server.js
```

> Si vous avez un souci, vous pouvez utiliser l'image Docker de ce serveur :
> ```bash
> docker run -p 8080:8080 chaouchi/fetch-demo-server
> ```

3. Testez les trois routes du serveur avec la commande `curl` :

```bash
curl http://localhost:8080/
curl http://localhost:8080/hello-text
curl http://localhost:8080/fruits-json
```

Vous devriez voir dans la console les données envoyées au client.

> Par défaut, curl n'affiche que le body de la réponse HTTP (les données demandées par le client).
> Il est possible d'afficher la requête et la réponse HTTP complètes avec l'option --verbose :
> `curl --verbose http://localhost:8080/hello-text`

### Fetch le serveur GET /

La fonction fetch() permet d'effectuer une requête HTTP.

```js
fetch("http://localhost:8080");
```
> Regardez dans la console du navigateur, notre serveur a reçu la requête !

Fetch est une fonction non-bloquante (asynchrone), ce qui veut dire qu'elle ne peut pas fournir son résultat directement en valeur de retour pour un opérateur `=`.

#### Récupérer la réponse HTTP avec then()

La fonction fetch retourne une `Promise<HttpResponse>`, c'est-à-dire une promesse asynchrone de la réponse HTTP de notre serveur.

> Une fonction asynchrone est une fonction qui renvoie son résultat après l'exécution complète du script.

La réponse HTTP du serveur se trouve dans la fonction `then()` de l'objet `Promise` retourné.

```js
fetch("http://localhost:8080").then(response_obj => {
    console.log(response_obj)
});
```

Une réponse HTTP est faite de plusieurs informations, mais la donnée la plus importante est le `body`, le corps de texte écrit (write) par le serveur.

Le body est récupérable sous différents formats : `text`, `bytes` ou `json`.

#### Récupérer le body avec un second then()

La fonction `response_obj.text()` *retourne* une `Promise<string>`. La sérialisation du body en caractères est une opération asynchrone car elle peut prendre beaucoup de temps dans le cas de gros volumes de texte transférés.

Je peux récupérer le texte du body dans le `then()` suivant si je retourne la valeur de retour de la fonction `response_obj.text()` dans la fonction callback du premier `then()`.

*script.js*
```js
fetch("http://localhost:8080").then(response_obj => {
    return response_obj.text();
}).then(body_str => {
    console.log(body_str);
})
```

Voici une version fortement commentée pour vous aider à appréhender l'ordre d'exécution des opérations asynchrones.

```js
fetch("http://localhost:8080")
.then(res_obj => {
    // Je log la réponse HTTP
    console.log(res_obj)
    // Le body de la réponse est un tableau d'octets : { 'a','b','c','d'}
    // Node me fournit une fonction res_obj.text() pour lire le body en tant que string
    return res_obj.text();
})
.then(body_str => {
    // Le résultat du premier then se trouve dans le suivant !

    // J'affiche le body
    console.log(body_str)
})
.catch(err_obj => console.log(err_obj));
```

#### Syntaxe courte du fech.then.then avec async await

```js
async functionmain (){

    const body_str = await fetch("http://localhost:8080").then(res => res.json())
    console.log(body_str)

}
main();
```

#### Bonus `res_obj.arrayBuffer()`

Si vous souhaitez lire le résultat en octets, il est possible de récupérer un tableau d'entiers plutôt qu'une string.

La route `/` renvoie 'abcd', soit 97 98 99 100 dans le tableau ASCII.

```js
fetch("http://localhost:8080/")
.then(res_obj => res_obj.arrayBuffer()) // lecture binaire du body
.then(buffer_obj => {
    const bytes_arr = new Uint8Array(buffer_obj);
    console.log(bytes_arr)
})
```
