# Utiliser Fetch et DOM

Comment pour toute chose en JavaScript, il faut penser en événements.

`Quand je ... ALORS je ...`

Action et concéquence c'est le principe même des événements.

Par exemple :

- Quand je clique sur un bouton ALORS j'execute console.log
- Quand je clique sur une image ALORS je modifier son attribut src
- Quand j'appuie sur ENTREE ALORS j'effectue un fetch()
- Quand je recoit le résultat d'un fetch() ALORS je modifie le DOM
