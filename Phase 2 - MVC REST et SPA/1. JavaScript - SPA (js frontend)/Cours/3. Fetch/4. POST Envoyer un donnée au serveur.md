### 1. **Serveur PHP qui renvoie un tableau (array)**

#### Backend (PHP)
```php
<?php
// Exemple : Serveur qui renvoie un tableau simple
header('Content-Type: application/json');
echo json_encode(["Alice", "Bob", "Charlie"]);
?>
```

#### Frontend (JavaScript)
```javascript
// Récupérer les données en utilisant fetch
fetch('http://localhost/votre-serveur.php')
  .then(response => response.json())
  .then(data => {
    console.log(data); // Affiche ["Alice", "Bob", "Charlie"] dans la console
    document.body.innerHTML = `<ul>${data.map(item => `<li>${item}</li>`).join('')}</ul>`;
  })
  .catch(error => console.error('Erreur:', error));
```

### 3. **Coder un backend qui renvoie une table SQL**

#### Backend (PHP)
```php
<?php
// Connexion à la base de données
$dsn = 'mysql:host=localhost;dbname=testdb;charset=utf8';
$username = 'root';
$password = '';
$options = [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION];

try {
    $pdo = new PDO($dsn, $username, $password, $options);
    $stmt = $pdo->query('SELECT * FROM ma_table');
    $result = $stmt->fetchAll(PDO::FETCH_ASSOC);

    header('Content-Type: application/json');
    echo json_encode($result);
} catch (PDOException $e) {
    echo json_encode(['Erreur' => $e->getMessage()]);
}
?>
```

#### Frontend (JavaScript)
```javascript
// Fetch pour récupérer une table SQL
fetch('http://localhost/votre-serveur.php')
  .then(response => response.json())
  .then(data => {
    console.table(data); // Affiche la table dans la console
    document.body.innerHTML = `<table border="1">
      <tr>${Object.keys(data[0]).map(key => `<th>${key}</th>`).join('')}</tr>
      ${data.map(row => `<tr>${Object.values(row).map(value => `<td>${value}</td>`).join('')}</tr>`).join('')}
    </table>`;
  })
  .catch(error => console.error('Erreur:', error));
```

### 4. **Coder un serveur qui reçoit une requête POST et ajoute un élément**

#### Backend (PHP)
```php
<?php
// Ajouter un élément dans une table via POST
$dsn = 'mysql:host=localhost;dbname=testdb;charset=utf8';
$username = 'root';
$password = '';
$options = [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION];

try {
    $pdo = new PDO($dsn, $username, $password, $options);

    // Récupérer les données POST
    $data = json_decode(file_get_contents('php://input'), true);

    if (isset($data['nom']) && isset($data['age'])) {
        $stmt = $pdo->prepare('INSERT INTO ma_table (nom, age) VALUES (:nom, :age)');
        $stmt->execute(['nom' => $data['nom'], 'age' => $data['age']]);
        echo json_encode(['success' => true, 'message' => 'Données insérées']);
    } else {
        echo json_encode(['success' => false, 'message' => 'Paramètres manquants']);
    }
} catch (PDOException $e) {
    echo json_encode(['Erreur' => $e->getMessage()]);
}
?>
```

#### Frontend (JavaScript avec un formulaire)
```html
<form id="ajoutForm">
  <input type="text" id="nom" placeholder="Nom" required>
  <input type="number" id="age" placeholder="Âge" required>
  <button type="submit">Ajouter</button>
</form>
<div id="message"></div>

<script>
  const form = document.getElementById('ajoutForm');
  form.addEventListener('submit', function(event) {
    event.preventDefault();
    
    const nom = document.getElementById('nom').value;
    const age = document.getElementById('age').value;

    fetch('http://localhost/votre-serveur.php', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ nom, age })
    })
    .then(response => response.json())
    .then(data => {
      document.getElementById('message').innerText = data.message;
    })
    .catch(error => console.error('Erreur:', error));
  });
</script>
```

### Remarque
- Assurez-vous d'avoir un environnement local pour exécuter le serveur PHP (par exemple, XAMPP, WAMP, ou Laravel Valet).
- Remplacez `http://localhost/votre-serveur.php` par l'URL réelle de votre script PHP.
- Configurez votre base de données MySQL avec une table adaptée (`ma_table`) pour les exemples SQL.
