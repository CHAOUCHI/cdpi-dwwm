# Démonstration de fetch et comment s'en servir ?

Ici je vais vous faire une démonstration de la fonction fetch qui permet de faire une requête HTTP en JavaScript.

> Vous allez vous rendre compte que la syntaxe peut être déroutante au début, voilà pourquoi dans le cours suivant je vous montrerai une autre syntaxe plus simple et naturelle à comprendre.


## Tester `fetch` avec une API REST
Le code suivant affiche le nom des 10 premiers pokémons dans la console.
```js
fetch("https://pokebuildapi.fr/api/v1/pokemon/limit/10")
.then(response_obj => response_obj.json())
.then(pokemons_arr => {
    pokemons_arr.forEach(pokemon_obj => {
        console.log(pokemon_obj.name);
    });
});
```

```

Salamèche
```

J'utilise l'API REST Pokebuild, un serveur de données contenant tous les pokémons. On accède à ces données via des requêtes HTTP, que l'on peut donc récupérer en JavaScript grâce à la fonction `fetch()`.

Je peux donc afficher les noms à l'écran en ajoutant une balise `<p>` dans le body **pour chaque** pokémon du tableau pokemons.

J'ai également ajouté une balise `p.loading` qui disparaît quand les données sont chargées, pour simuler un temps de chargement le temps que la réponse soit reçu d'Internet.

```html

    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

        .then(response_obj => response_obj.json())
        .then(pokemons_arr => {
            const loadingTag_elem = document.querySelector(".loading");
            loadingTag_elem.remove();

                console.log(pokemon_obj.name);
                // J'ai le nom du pokémon 
                // Je vais l'ajouter au body

                pTag_elem.textContent = pokemon_obj.name;
                
                // J'ajoute la balise dans le body
                document.body.appendChild(pTag_elem);
            });
        });
    </script>
    
</body>
</html>
```

### Comment se servir de la méthode `fetch()` ?
*Documentation MDN* : https://developer.mozilla.org/fr/docs/Web/API/Fetch_API/Using_Fetch

Une utilisation classique de fetch veut que l'on envoie une requête à un serveur de données. C'est-à-dire un serveur qui renvoie des données brutes sans aucun formatage visuel.

Dans la plupart des cas, un serveur de données ne renvoie pas du HTML mais du JSON, un format de données représentant un tableau d'objets JavaScript sous la forme d'une chaîne de caractères.

*Fetch* signifie *récupérer* en anglais et *then* signifie *ensuite*. Il faut voir la syntaxe de fetch comme ceci : 

1. "I **fetch** some data from an url ..."
2. "**then** I transform the JSON response to a JavaScript array ..."
3. "**then** I use the data."

#### Code : 
```js
fetch(url_str)          // Remplacez l'url par l'url de la requête HTTP à exécuter
.then(function(reponseHTTP_obj) {    // La fonction callback fournit la réponse HTTP
    // Les données JSON sont transformées en un tableau JS
    return reponseHTTP_obj.json();      
})
.then(function(data_arr) {    // la 2nde fonction callback fournit les données   
    console.log(data_arr);
    // Utiliser les données ici ...
});
```
