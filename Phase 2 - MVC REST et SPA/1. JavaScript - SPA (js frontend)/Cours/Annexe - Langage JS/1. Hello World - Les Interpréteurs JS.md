
# Les interpréteurs JavaScript

> Environnement d'exécution : le programme ou système qui exécute le code.

Un environnement d'exécution est aussi appelé "*runtime environment*" ou juste *runtime*.

## Les environnements d'exécution de JavaScript

JavaScript propose deux choix d'environnement d'exécution : 
- **NodeJS** : un programme codé en C++ qui utilise le moteur V8 (Google) pour interpréter le code. Il donne accès à l'OS via des API similaires à l'encapsulation des appels systèmes.
- Un **navigateur web** qui va exécuter le code via un interpréteur et donner accès au navigateur via des APIs.

## Installer NodeJS
Installez NodeJS pour interpréter du JS.

Téléchargez ici : https://nodejs.org/fr

Sous Linux :
```bash
apt install nodejs
```

## Interpréteur NodeJS

Exécutez NodeJS : 
```
node
```
Puis tapez cette ligne de code pour afficher Hello World :
```
console.log("Hello World!");
```

Vous devriez voir ceci dans la console :
```
Hello World
undefined
```
`Hello World` est affiché grâce à la fonction log que nous avons appelée. Rien d'étonnant.

*`undefined`* par contre, c'est la valeur de retour de la fonction `log`, au même titre que `printf()` retourne void en C, `console.log()` renvoie *`undefined`* en JS.

`undefined` est la valeur de retour d'une fonction qui n'a pas d'appel à `return` ; l'équivalent de `void` en C donc.

Par défaut, le CLI Node affiche la valeur de retour de la commande que l'on tape. 

Par exemple, tapez :
```
24
```
``node`` devrait vous afficher `24`, la valeur de retour de 24. Logique.

C'est très pratique car Node affiche des informations très utiles à propos des objets ou simplement pour connaître le type d'une fonction.

Tapez ceci pour connaître le contenu de la variable `global` :
```js
global
```
La variable `global` est en quelque sorte la grosse variable globale qui contient toutes les variables de notre programme JavaScript.

Elle contient par exemple la fonction setTimeout qui permet de programmer une fonction pour plus tard.

1. Affichez "Bonjour tout le monde" à l'écran.
2. Testez NodeJS pour faire des calculs comme `5*6/78`.
3. Affichez la valeur de retour de la fonction `console.log`. Que signifie `undefined` et selon vous pourquoi la fonction log retourne-t-elle `undefined` ?
4. Affichez le contenu de l'objet `global` et cherchez les fonctions `setTimeout` et `setInterval`.

## Un fichier source .js
Créez un fichier nommé *main.js* qui contient ce code : 

```js
let age = 25;
const prenom = "Massinissa";
console.log("Salut !");
console.log("Je m'appelle " + prenom + " et j'ai " + age + " ans !");
```

## Exécuter le code source avec NodeJS 
Dans le shell Linux, tapez :
```bash
node main.js
```
1. Observez le résultat.

Voyez comme le `+` accepte des chaînes de caractères en tant qu'opérandes, chose impossible en C !

2. Selon vous, quelles sont les nouvelles capacités de l'opérateur `+` en JavaScript par rapport à son utilisation habituelle pour les additions de nombres (int ou float) en C ?

## Exécuter le code source avec un navigateur

Pour exécuter du JS dans le navigateur, créez deux fichiers :

- index.html
- script.js

*index.html*
```html
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    
</body>
<script src="script.js"></script>
</html>
``` 

*script.js*
```js
console.log("Hello World");
```

1. Ouvrez votre site web avec un navigateur.

> Utilisez l'extension VSCode : Live Preview si vous n'avez pas de serveur web.

2. Ouvrez la console : Clic Droit > Inspecter > Console ou F12 > Console

***Si vous voyez écrit 'Hello World' dans la console, c'est que tout fonctionne.***

Vous pouvez donc coder dans le fichier script.js.
