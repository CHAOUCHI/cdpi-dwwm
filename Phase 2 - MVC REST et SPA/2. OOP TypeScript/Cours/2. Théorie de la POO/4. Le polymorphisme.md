
## Le polymorphisme

Le polymorphisme permet à une classe enfant de modifier les méthodes `protected` et `public` de sa classe parente.

```ts
class Animal {
    private name: string;
    private espece: string;

    constructor(name: string, espece: string) {
        this.name = name;
        this.espece = espece;
    }

    public info() {
        console.log(this.name, "est un", this.espece);
    }

    public crier() {
        console.log("L'animal crie !");
    }
}
class Chat extends Animal {
    // La classe Chat redéfinit la méthode crier
    crier() {
        console.log("Miaou !");
    }
}
class Chien extends Animal {
    // La classe Chien redéfinit la méthode crier
    crier() {
        console.log("Ouaf !");
    }
}
const chat = new Chat("Caramel", "Felis silvestris");
const chien = new Chien("Médor", "Canis lupus");
const dinosaure = new Animal("Trex", "Tyrannosaurus");

chat.crier();        // => Miaou !
chien.crier();       // => Ouaf !
dinosaure.crier();   // => L'animal crie !
```

> Le polymorphisme est possible uniquement pour les méthodes `public` ou `protected` de la classe mère. Les méthodes `private` sont par définition inaccessibles, il est donc impossible de les modifier.

Le polymorphisme permet de définir un comportement par défaut et d'assurer une constance dans le nommage des méthodes des classes filles. Peu importe la classe, tant qu'elle hérite de la classe `Animal`, le cri se produit avec la méthode `crier()`.

C'est d'autant plus pratique lorsqu'une fonction nécessite un `Animal` en paramètre mais n'a pas besoin de savoir s'il s'agit d'un chat ou d'un chien.

```ts
class Zoo {
    private animals: Animal[] = [];
    addAnimal(newAnimal: Animal) {
        this.animals.push(newAnimal);
    }
    showAnimals() {
        console.log("Bonjour mes petits :)");
        this.animals.forEach(animal => {
            animal.crier();
            animal.info();
        });
    }
}
const zoo = new Zoo();
zoo.addAnimal(new Chat("Minette", "Felis silvestris"));
zoo.addAnimal(new Chien("Patapouf", "Canis lupus"));
zoo.addAnimal(new Animal("Raptor", "Velociraptor"));
zoo.showAnimals();
```
*Résultat dans la console*
```bash
Bonjour mes petits :)
Miaou !
Minette est un Felis silvestris
Ouaf !
Patapouf est un Canis lupus
L'animal crie !
Raptor est un Velociraptor
```

### La généricité
La généricité, c'est la capacité d'un code à être modulaire : plusieurs classes peuvent être utilisées de façon interchangeable grâce à l'héritage, et le polymorphisme permet de garder une constance dans le nommage des méthodes à travers toutes ces classes.
```ts
// addAnimal(newAnimal: Animal) { ... }
zoo.addAnimal(new Chat("Minette", "Felis silvestris"));
zoo.addAnimal(new Chien("Patapouf", "Canis lupus"));
zoo.addAnimal(new Animal("Raptor", "Velociraptor"));
```
Dans le cas de la POO, une classe comme `Animal` peut être utilisée comme type attendu des paramètres d'une méthode, même si la classe effective est un `Chat` ou un `Chien`.

L'héritage et le polymorphisme permettent donc une généricité de notre code. En complément, l'encapsulation permet de rendre les objets faciles d'utilisation via des méthodes publiques.  
Le tout forme une base de code évolutive et plus rapide à développer qu'une base de code procédurale classique.
