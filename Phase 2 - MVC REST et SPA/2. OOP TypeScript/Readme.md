# Plan d'action

Dans ce cours un peu à part du reste, nous allons apprendre à faire de la programmation orientée objet (POO) en prenant comme prétexte la création d'un petit framework de jeu vidéo 2D.

- Création d'une boucle (while) d'événements.
- Classes et objets pour représenter les briques logiques de l'application (Assets, GameObjects, Audio, Input).
- Héritage pour simplifier la création de nouvelles briques (GameObjects).

## 1. Cours/1. Sans POO
Démarrer la création du jeu jusqu'à être bloqué par le manque de structure. Nous nous rendrons ainsi compte de l'utilité de la POO.

## 2. Cours/2. Théorie de la POO
Consulter le cours sur la POO pour apprendre les bases de la programmation orientée objet en TypeScript.

## 3. Projet Earth Defender
Reprendre la création du jeu depuis le début avec plus de structure grâce aux fonctionnalités de la Programmation Orientée Objet (POO).

- Classes : pour diviser le code en briques logiques réutilisables.
- Héritage : pour factoriser le code et faciliter la création de nouvelles briques.
- Polymorphisme : pour créer des événements dans notre framework (OnUpdate, OnCollision, OnStart, etc.).
