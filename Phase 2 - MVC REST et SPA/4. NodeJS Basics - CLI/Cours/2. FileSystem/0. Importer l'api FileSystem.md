# File System - Accéder aux fichiers avec Node.js

L'API du file system permet de créer, lire ou écrire dans des fichiers, c'est-à-dire les fichiers de l'ordinateur qui exécute notre script. L'API file system de Node.js est accessible via un import depuis le module fs.

```js
import fs from "fs";
```

L'API file system permet également de créer, lire ou modifier les droits d'administration sur des dossiers ou des fichiers. Elle est donc très puissante.

Nous nous limitons ici uniquement à la création, l'écriture ou la lecture de fichiers.

Je peux analyser le contenu de l'API file system en faisant un `console.log(fs)`.

```js
import fs from "fs/promises";
console.log(fs);
```

1. Cherchez les fonctions suivantes dans le console.log(fs) :
    - readFile
    - writeFile
    - appendFile
    - mkdir
    - readdir

2. Essayez de comprendre à quoi elles servent en lisant la documentation officielle de NodeJS : https://nodejs.org/api/fs.html

> Faite un Ctrl-F pour chercher une fonction dans la page, c'est plus rapide. ;)

## Exemple de l'utilisation de l'API file system

Voici un exemple complet et commenté de l'utilisation de l'API File System avec Node.js, en utilisant les fonctions asynchrones et `async/await` :

```js
import fs from "fs/promises";

main_func();

async function main_func() {
     try {
          // 1. Écrire dans un fichier
          await fs.writeFile("exemple.txt", "Bonjour, monde !");
          console.log("Fichier écrit avec succès.");

          // 2. Lire le contenu du fichier
          const data_str = await fs.readFile("exemple.txt", "utf8");
          console.log("Contenu du fichier :", data_str);

          // 3. Ajouter du contenu au fichier
          await fs.appendFile("exemple.txt", "Ligne ajoutée.\n");
          console.log("Ligne ajoutée au fichier.");

          // 4. Créer un dossier
          await fs.mkdir("nouveau_dossier");
          console.log("Dossier créé ou déjà existant.");

          // 5. Lire le contenu du dossier courant
          const files_arr = await fs.readdir(".");
          console.log("Fichiers dans le dossier courant :", files_arr);

     } catch (err_obj) {
          console.error("Erreur :", err_obj);
     }
}
```
