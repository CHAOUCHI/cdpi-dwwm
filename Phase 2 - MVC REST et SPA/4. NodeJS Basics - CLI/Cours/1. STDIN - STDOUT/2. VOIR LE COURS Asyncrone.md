# Lisez LE COURS Asynchrone !

Lisez le cours asynchrone pour découvrir comment les fonctions asynchrones sont prises en compte dans la boucle d'événements de JavaScript.

Pratiquez avec des exercices qui vous permettront de comprendre dans quel ordre les fonctions sont exécutées lorsque vous utilisez des fonctions fléchées.

J'y ai également placé une animation qui permet de comprendre la boucle d'événements et comment les fonctions peuvent être mises de côté par JavaScript pour effectuer des opérations asynchrones plus tard.
