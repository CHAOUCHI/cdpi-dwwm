# Projet CopyPaster-Node

Un programme Node.js en CLI qui permet de copier un fichier comme le fait la commande `cp`.

## Commandes du programme

### **Copier un fichier**
```bash
node copy-paster.js mon_fichier
> Fichier créé avec succès.
```

### Cas d'erreur

#### Argument file_path manquant
Si l'utilisateur oublie de préciser le chemin vers le fichier dans les paramètres de la ligne de commande, indiquez-lui son erreur via un message d'erreur clair.
```bash
node copy-paster.js
> Argument file_path manquant. Veuillez préciser le chemin du fichier.
node copy-paster.js chemin/du/fichier
```

#### Fichier inexistant
Si l'utilisateur se trompe dans le nom du fichier et tente de copier un fichier qui n'existe pas, indiquez-lui son erreur via un message.
```bash
node copy-paster.js mon_fjskej
> Fichier inconnu : mon_fjskej. Aucun fichier de ce nom trouvé.
```

## Cahier des charges

| Tâches | Description |
|-|-|
| Copier un fichier et le renommer avec un nom différent mais reconnaissable. | Le nom du fichier est fourni en argument du CLI. Vous pouvez accéder à ses arguments avec la liste `argv` disponible dans l'API `process`. (VSCode fait les imports automatiquement). |
| Couverture d'erreur | Mettez en place au minimum les messages d'erreur décrits dans la section *cas d'erreur*. |
