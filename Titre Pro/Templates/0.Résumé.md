# Résumé

> Voici la première étape de votre projet : le résumé. Il s'agit d'un document d'une page qui présente votre projet de manière synthétique. Il doit inclure les éléments suivants :
- **Titre du projet** : Un titre accrocheur qui reflète l'essence de votre projet.
- **Description** : Une brève description de votre projet, expliquant a quoi et a qui il sert.
