# Personas


> Deuxième Etape : Pour pouvoir definir les entity, les roles, les use cases et meme les user stories, il est important de definir les personas. Les personas sont des représentations fictives de vos utilisateurs cibles. Ils vous aident à comprendre les besoins, les motivations et les comportements de vos utilisateurs, ce qui vous permet de concevoir une application qui répond à leurs attentes.

Exemple de persona :
| Persona | Description |
|---------|-------------|
| **Nom** | [Nom du persona] |
| **Tranche Âge** | [Tranche d'âge du persona] |
| **Profession** | [Profession du persona] |
| **Objectifs** | [Objectifs du persona en utilisant l'application] |
| **Frustrations** | [Frustrations ou problèmes rencontrés par le persona] |
| **Comportements** | [Comportements ou habitudes du persona en lien avec l'application] |
