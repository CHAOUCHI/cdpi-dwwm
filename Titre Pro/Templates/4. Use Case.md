
Le Use Case est un diagramme qui permet de représenter les différentes interactions entre les utilisateurs et le système. Il permet de visualiser les différentes fonctionnalités de l'application et les différents types d'utilisateurs qui interagissent avec elle.


Rendez-vous sur : http://draw.io pour le rédiger.

## Souvenez vous :

1. Un Use case contient un sujet et un verbe
2. Un Use case doit être compréhensible par tous les membres de l'équipe, y compris les non-techniciens.
3. Un Use case qui dépend d'un autre Use case doit être relié à celui-ci par une flèche incluant le mot "include".
4. Un Use case qui étend un autre Use case doit être relié à celui-ci par une flèche incluant le mot "extend". (Un use case qui étend un autre use case est une action optionnelle)
5. Placer le use case de connexion à droite pour que les autres use cases puissent l'include facilement.
